## Featured Projects

### SysGuard

**Lightweight Centralized Infrastructure Monitoring and Remote Management Platform**

SysGuard is my final-year project focused on centralized infrastructure monitoring, remote management, failure detection, controlled recovery, event logging and observability.

The project explores how infrastructure administrators can monitor and manage remote Linux servers while reducing the need for physical visits to server locations.

It integrates networking, Linux systems administration, monitoring technologies, automation and database management into a practical infrastructure management environment.

The operational workflow follows:

**Monitor → Detect → Remotely Access → Diagnose → Recover → Verify → Record / Alert**

Technologies and concepts:

`Linux` `Python` `Docker` `Prometheus` `Grafana` `Node Exporter` `SQLite` `Telegram` `GNS3` `VyOS` `VRRP` `High Availability`

**Status:** In Development.

### Operation Blackout

**Enterprise Network Design & Simulation**
